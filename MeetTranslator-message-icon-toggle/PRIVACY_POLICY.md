# Privacy Policy — Meet Japanese Translator

**Last updated:** 2 November 2026

Meet Japanese Translator is a Chrome extension that helps translate Japanese text on Google Meet and translate text that a user types into the Meet chat editor.

## Information processed

When translation is used, the extension sends the text being translated and the selected source and target language codes to Google's translation service at `translate.googleapis.com`. The extension does not operate its own server and does not intentionally collect names, email addresses, meeting links, account credentials, or analytics.

The incoming-translation feature is off by default. If a user turns it on, the extension checks text rendered on the Google Meet page for Japanese characters and may submit matching text for translation. This can include text visible in the meeting interface, not only chat messages. Users can turn the feature off at any time.

## How information is used

Text is sent only to request the translation or Romaji conversion selected by the user, or to support the enabled incoming-translation feature. Translation requests are handled by Google; Google's handling of submitted text is governed by Google's applicable terms and privacy policy.

## Storage and sharing

The extension does not store translation text on a developer-controlled server. Translation text is shared with Google only to provide the requested translation service. The extension does not sell user data.

## Permissions

The extension runs on `https://meet.google.com/*` to provide its interface and interact with the Meet chat page. It connects to `https://translate.googleapis.com/*` to request translations.
